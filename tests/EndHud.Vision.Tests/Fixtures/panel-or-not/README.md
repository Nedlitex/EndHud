# panel-or-not

Screens that decide whether the squad panel is on screen (`PartyState.PanelVisible`), kept out of
the sweeps over `Fixtures/*` (naming, screen sizes) because they aren't ordinary panel screenshots.
From the owner's recordings, UID blacked out.
