# Faded squad portraits in battle

Readings from a 4K boss fight (Typhoeus, Arcane, Perlica, Liino, by eye), four a second as the app
takes them, scaled to 1920x1080. Everything is blacked out but the band with the squad panel,
skill-point bar and skill buttons; the ping and player UID under it are blacked out too. Each file
is named for its time in the recording (`t031_50.jpg` = 31.5 s).

- 14–15 s: every portrait clear (the squad gets named).
- 21–22.5 s and 30.5–37 s: the game draws some portraits see-through, with bright effects behind
  them. Matched on their own they look like another operator (Purrchena), or like no one.
