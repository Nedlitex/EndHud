# EndHud

**《明日方舟：终末地》游戏辅助面板。** 提供连携技就绪提示（含倒计时）、按战斗状态切换的排轴，以及全队终结技、干员专属计数和连击等增益的状态监视。键鼠和[手柄](#手柄)均支持，战斗中可随时切换。

![实战录像（庄方宜小队）：上方是排轴，左侧是连携技提示](docs/images/demo-battle.webp)

EndHud 独立运行，仅通过读取屏幕画面获取信息，方式与录屏软件相同。它不打开、读取或修改游戏进程，不注入代码，也不代替玩家操作游戏。

## 功能

### 连携就绪提示

战斗中，干员的连携技冷却结束时，屏幕上滑入提示。以下为实战录像（“一直显示”模式）。

![即将就绪的连携技颜色偏灰蓝并倒计时，就绪时变为金色并闪动](docs/images/combo-countdown.webp)

![四位干员的连携技全部就绪，提示依次滑入](docs/images/combo-ready.webp)

![使用连携技后，对应的提示滑出，下面的提示随之上移](docs/images/combo-used.webp)

- **显示方式**（在菜单中选择）：
  - **冷却结束时提示**：显示 2、3 或 5 秒（默认 3 秒）后滑出。
  - **一直显示直到再次使用**：连携技就绪期间持续显示。
- **提前提示**：就绪前显示倒计时（例如“0.5 秒后就绪”），可设为关闭、0.5、1、2 或 3 秒，默认 1 秒。倒计时中为灰蓝色，就绪时边框变为金色并闪动一次。
- **位置**：打开菜单（Ctrl+Shift+M）后可拖动提示框；“恢复默认位置”可复原。位置按游戏窗口比例保存。
- 冷却被技能提前刷新时同样提示；终结技动画期间结束的冷却，在画面恢复后提示。
- 非战斗状态、已阵亡的干员，以及战斗开始时已就绪的连携技不提示。

### 自动识别干员

EndHud 根据小队栏头像自动识别小队中的干员（一至四人），并在提示中显示对应的名字和头像。干员头像库随程序提供；游戏推出新干员后，头像库通过“检查更新”自动更新。

小队栏出现后约一秒内完成识别，识别完成前不显示连携提示。战斗中头像被特效遮挡或变淡时，识别结果保持不变；更换小队后自动重新识别。如有识别错误，可在菜单的“干员识别”中为该位置指定正确的干员，EndHud 会记住该选择。

### 排轴

可为每个小队编写排轴（战技、连携技、终结技的使用顺序）。战斗中，屏幕上方显示排轴，并**根据当前战斗状态显示对应的轴段**，样式与常见排轴图一致。

![庄方宜集齐 9 把青霆剑、终结技就绪时，排轴自动切到爆发轴](docs/images/rotation-burst.webp)

![排轴编辑器：左侧是轴段和显示条件，右侧是步骤，下方是排轴预览](docs/images/rotation-editor.png)

- **按小队自动加载**：识别出小队后，自动加载为这四位干员编写的排轴，与站位顺序无关。
- **轴段与条件**：排轴由若干轴段组成（例如“充能轴 I”“充能轴 II”“爆发轴”），每个轴段设有显示条件，例如充能轴 I：“猎矢 = 4，诀和梨诺的终结技均未就绪”；爆发轴：“猎矢 = 0、启示 = 8，诀和梨诺的终结技充能均 ≥ 80%”。EndHud 显示第一个满足条件的轴段（也可设为显示最后一个）；均不满足时显示没有条件的轴段，没有这样的轴段或条件暂时看不到时（例如终结技动画）保持当前轴段。条件可通过“全部满足 / 任一满足”的条件组组合，每个条件都可勾选“非”表示相反。
- **步骤显示**：EndHud 无法得知玩家按下的按键，因此轴段中的各步骤样式相同，按顺序列出，并附带备注（例如“重击后”“再普攻×5”）。
- **样式**：半透明灰色横条，两端渐隐，默认位于屏幕上方正中。
- **可用条件**（均从列表中选择）：
  - 技力：至少 / 至多 / 等于某个值；
  - 某位干员的连携技或终结技：就绪 / 已使用；
  - 连携技冷却、终结技充能：至少 / 至多某个百分比（终结技充能“至多 0%”即刚放完）；
  - 战技：就绪 / 冷却中；
  - 干员资源：莱万汀的“熔火”（0–4）、提弗洛斯的“猎矢”（0–4）和“启示”（0–8）、庄方宜的“青霆剑”（0–9）；
  - 敌人状态：有 / 没有某种附着或异常（例如灼热附着、导电）；
  - 当前操控的干员；
  - 终结技持续中：莱万汀、庄方宜等终结技持续期间（读取技力条上方的持续时间条）。
- **跟踪范围**：仅跟踪技能，不含普通攻击。战技按数字键 1–4 释放。
- **推荐排轴**：EndHud 自带推荐排轴（编辑器中标有【推荐】），随“检查更新”每日更新。修改推荐排轴后保存为自己的排轴，原推荐排轴继续更新；已删除的推荐排轴可通过“恢复推荐排轴”找回。
- **分享**：可在编辑器中导出为文件或复制分享码（以 `EHR1:` 开头），他人导入文件或粘贴分享码即可使用。导入同一排轴时可选择替换或另存为副本。
- **显示时机**：仅在战斗中、且当前小队有对应排轴时显示；特效遮挡或终结技动画期间保持显示，战斗结束数秒后隐藏。
- **位置、大小与不透明度**：打开菜单（Ctrl+Shift+M）时，即使不在战斗中也会显示排轴示例（有当前小队的排轴时显示其第一个轴段），可直接拖动调整位置；菜单中可调整大小（50%–200%）和不透明度（20%–100%）；“恢复默认位置”可复原。

打开编辑器：菜单“排轴”一栏的“编辑排轴…”，或右键托盘图标选择“编辑排轴”。排轴保存在 `%APPDATA%\EndHud\rotations`。

### 状态监视

战斗中，屏幕下方中间以一排圆形图标显示全队状态，图标中间为干员头像。

![状态监视：连击、每位干员的终结技和专属计数](docs/images/gauges.png)

- **终结技**：外圈按充能进度填充（金色），就绪时整圈发光；右下角为终结技图标。莱万汀、庄方宜这类持续一段时间的终结技释放后，图标改为紫色发光的圆环，显示剩余持续时间（从满圈逆时针减少），下方标“持续中”。
- **专属计数**：例如庄方宜的青霆剑（0–9）、提弗洛斯的猎矢（0–4）和启示（0–8）、莱万汀的熔火（0–4）。外圈每格代表一层，右下角显示当前数值，集满时变为金色并发光。游戏仅在操控该干员时显示这些计数，切换干员后显示最后一次读取的数值（变暗显示）。
- **连击**：游戏在血条左侧显示连击时，最左侧图标亮起（绿色），圆环按层数分为四段，右下角显示当前层数（最多 4 层）；连击结束后变暗，并在本场战斗中保留。未出现过连击时不显示该图标。
- 干员倒下时，对应图标变暗；被特效遮挡而无法读取时，外圈留空。
- **显示时机**与排轴相同。打开菜单（Ctrl+Shift+M）可拖动位置；“状态监视”一栏的“大小”滑块可调整图标大小（50%–200%）。

### 缘缘庄助手

**营业前**：在“营业设定”“安排干员”“设定菜单”这几个画面上，屏幕右侧中间显示按档位排好的推荐：每个厨房擅长做什么、该放哪些干员，菜单上哪些菜和饮品。干员带头像、菜和饮品带图片，方便在列表里按图找；没有的干员或菜，换同一档的就行：

```
缘缘庄 · 推荐（没有的干员/菜换同档的）
厨房一（主食）：T1 [头像]昼雪 [头像]秋栗　T3 [头像]卡契尔 [头像]大潘 [头像]弭弗
厨房二（菜肴）：T1 [头像]埃特拉 [头像]梨诺　T2 [头像]明河 [头像]佩丽卡　T3 …
厨房三（甜品）：T1 [头像]伊冯 [头像]艾维文娜　T3 …
菜单：T1 [图]青菜养生粥 [图]界龙肉卷 …　T2 [图]红蕊奶酪蛋糕 …　T3 …
饮品：T1 [图]瓶装霞莓饮 [图]陈酿葡萄露 [图]潮前龙井　T3 …
```

- 只需看一眼“营业设定”：按画面上的主题、热门特性、主题要求、厨房数和每个厨房的位置数来推荐。干员用 EndHud 自带的干员库（能下厨的都算，祀和管理员不能下厨），菜和饮品用自带的菜谱（按客栈等级解锁的，加上主题星级解锁的）。不需要打开“安排干员”翻列表，也不需要打开“设定菜单”；看过“设定菜单”时，会按上面的库存和菜单要求再修正。
- **T1** 是推荐的组合：每个厨房 T1 里的前几位就是建议放的干员，菜单的 T1 就是建议的菜单（满足全部菜单要求）。**T2**、**T3** 是替补：按 EndHud 的收益估算，T1 至少有最好的 90%，T2 至少 75%，T3 至少 50%。每档最多多列 3 个名字。
- 厨房或位置少时，行数也随之减少。主题被挡住时只显示“看不清主题（画面被遮挡）”，不会根据看了一半的内容推荐。
- 计算在后台进行，画面内容变化时才重新计算（约 2 秒），期间显示“正在推荐…”。
- 打开菜单可拖动推荐面板的位置，大小和不透明度与营业中的清单相同。

**营业中**：屏幕右侧显示一张建议清单，每个厨房一行，菜名旁都带图片，方便在派单时按图找菜：

```
开启满堂彩（R）
厨房一 建议排：[图]茄果鳞肉汤　[图]白瓜肉丸汤
厨房二 建议排：[图]金丝小贝
厨房三 建议排：（预做）[图]雪绵豆沙
桌3 的点单看不清
```

- **派单建议**：读取每桌点的菜，按“哪个厨房最快做好”分配到各厨房；空闲的厨房建议预做（标“（预做）”），不超过出餐台能放下的数量。营业一开始，在第一位客人点单之前，每个厨房就已排满预做的菜。没有要排的菜时显示“—”。
- **换菜**：新点单在某个厨房做最快、但那里排着预做的菜时，提示“厨房一 换：（预做）A → B（桌3）”。只会建议换掉预做的菜，不会动客人点的菜。
- **满堂彩**：灶中火满了提示“开启满堂彩（R）”；快满时（80 以上）提示“满堂彩快满了：先把厨房排满”，好让满堂彩期间有菜可上。满堂彩进行中不提示。
- **没有大厨的厨房不做菜**：营业设定里一个干员都没放的厨房，不会出现在清单里，也不会往那里派单或预做。
- **已上的菜**：桌牌上菜品下方的小格变绿，或菜品图上出现蓝色转圈（自动上菜），都算已经上了，不会再建议做这道菜。图上的绿色笑脸不代表什么，不看它。
- **收尾**：计时到 00:00 后，缘缘庄还会继续上菜 18 秒，收尾的判断都把这 18 秒算进去。营业结束前最后 40 秒不再预做，也不会预做来不及做出来的菜。某桌等的菜已经来不及做出来时（排在前面的菜加上烹饪时间，超过剩余时间），出餐台上剩下的菜会提示端给这桌，不一定要等到 00:00：有这桌点的菜就给它，没有就给别的菜，例如“收尾：把剩下的[图]肉包子 端给桌3（不对也有钱）”——上错的菜也能拿到一些钱，总比浪费好。来得及做出来的桌照常等它的菜；只等饮品的桌不会给菜（给了也不算上餐）。
- **老饕**：读出老饕说的话，用大白话说明要求（例如“要求：不要滋补的”），并列出菜单里符合的菜和饮品，以及在哪儿（“出餐台有”“厨房二约35秒”“饮品台”）；有两个要求时给出上菜顺序。认不出的要求会显示看到的字；菜单里没有符合的也会直说。
- **看不清就不猜**：某桌的点单图片认不出时，这桌不参与建议，只显示“桌3 的点单看不清”。
- 打开派单面板时，EndHud 会读取当前厨房的大厨和排队情况；没打开时，按做菜时间推算（老饕卡片里的时间标“约”）。如果开店前没经过营业设定和菜单设定界面，打开一次派单面板就能知道厨房和菜单。
- 只给建议，不会替你点击或操作游戏；不在游戏界面上画框。需要 Windows 的简体中文文字识别（“中文(简体，中国)”语言）；没有安装时，清单会提示如何安装。
- 营业中的清单只在营业中显示，推荐面板只在营业前的几个画面显示，战斗中都不显示。打开菜单可拖动两者的位置；“缘缘庄助手”一栏可调整大小（50%–200%）和不透明度、恢复默认位置，也可在托盘菜单中开关。

### 调试面板

在菜单中勾选“显示调试面板”或按 Ctrl+Shift+D 打开，显示每位干员的生命值、连携技冷却、终结技充能和等级；无法读取时显示原因。每次启动时默认关闭。

## 安装

1. 打开 **[Releases 页面](https://github.com/Nedlitex/EndHud/releases/latest)**，下载最新版本的 `EndHud-版本号.msi`。
2. 双击运行安装程序。安装完成后，开始菜单中会出现“EndHud”。
3. 安装新版本时会直接覆盖旧版本，设置保持不变。

> 首次运行时，Windows 可能提示“Windows 已保护你的电脑”（安装包暂未进行代码签名），点击“更多信息”→“仍要运行”即可。

**免安装版**：同一页面提供 `EndHud-版本号-portable.exe`，功能与安装版相同。

**卸载**：在“设置 → 应用 → 安装的应用”中找到 EndHud 并卸载。

### 系统要求

- Windows 10（2004 或更高版本）或 Windows 11。
- 游戏使用**无边框窗口**或**窗口**模式（独占全屏模式下，任何程序都无法显示在游戏上方）。

## 使用方法

1. 运行 EndHud，系统托盘中会出现金色“E”图标。
2. 切换到游戏时 EndHud 自动显示，切换到其他窗口时自动隐藏。
3. 进入战斗后，连携技冷却结束时显示提示。

### 快捷键

| 快捷键 | 作用 |
|---|---|
| **Ctrl+Shift+M** 或 **Ctrl+F9** | 打开/关闭菜单（设置、调整位置、指定干员） |
| **Ctrl+Shift+H** 或 **Ctrl+F10** | 显示/隐藏 HUD |
| **Ctrl+Shift+D** 或 **Ctrl+F11** | 显示/隐藏调试面板 |
| **Ctrl+Shift+Q** | 退出 EndHud |
| **Esc** | 关闭菜单 |

### 菜单设置

按 Ctrl+Shift+M 打开菜单，设置自动保存。各功能分栏显示，可通过右上角的“开启”单独关闭。

- **通用**
  - **游戏窗口获得焦点时自动显示 HUD**：关闭后需按 Ctrl+Shift+H 手动显示。
  - **开机时自动启动 EndHud**（默认关闭）：登录 Windows 后在托盘中自动运行，不弹出提示。也可以在任务管理器的“启动应用”中关闭；卸载 EndHud 时会一并移除。
  - **识别小队栏**：读取小队栏和战斗界面。连携就绪提示、排轴和状态监视均依赖此项（缘缘庄助手不依赖）。
  - **显示调试面板**。
  - **自动检查更新**：每天检查一次 EndHud 新版本、推荐排轴和干员头像库。
  - **自动安装 EndHud 新版本**（默认开启）：在游戏未运行时安装新版本并重新启动 EndHud。
  - **导出诊断信息**：见[常见问题](#常见问题)。
- **连携就绪提示**：显示方式、显示时长、恢复默认位置。
- **排轴**：大小（50%–200%）、打开排轴编辑器、恢复默认位置。
- **状态监视**：大小（50%–200%）、恢复默认位置。
- **缘缘庄助手**：大小（50%–200%）、不透明度、恢复默认位置。
- **干员识别**：为识别错误的位置指定正确的干员；“清除所有已学习的头像”可撤销全部手动指定。

托盘图标右键菜单还提供：游戏检测状态、自动显示、**缘缘庄助手**开关、调试面板、**编辑排轴**、**检查更新**、打开配置文件夹、**导出诊断信息**和退出。

### 更新

- **EndHud 新版本**：启动时及之后每天检查一次。默认在游戏未运行时自动下载、校验并安装新版本，然后重新启动，设置和数据保持不变。游戏运行期间发现的新版本会在游戏关闭后安装，也可以点击通知或托盘菜单中的“立即更新到 x.y.z”立即更新。关闭“自动安装 EndHud 新版本”后，发现新版本时仅显示通知。
- 更新失败时，当前版本继续正常运行，通知中会说明原因，点击可打开下载页面。
- **干员头像库**：运行期间定期检查，发现新干员时显示通知。
- **手动检查**：右键托盘图标选择“检查更新”，同时检查 EndHud、推荐排轴和干员头像库。

## 支持的分辨率

适用于台式显示器和笔记本，支持 100%–200% 的 Windows 显示缩放；提示框始终按游戏窗口比例显示。

| 游戏窗口 | 干员名字、连携提示、生命值、终结技、阵亡 | 等级（仅调试面板） |
|---|---|---|
| 4K、5K、2560×1440 及同级别（含 21:9、16:10） | ✅ | ✅ 大部分可识别 |
| 1920×1080 及同级别、1600×900 | ✅ | 约一半可识别 |
| 1366×768、1280×720 | ✅ | 不识别 |

## 手柄

![手柄实战：小队栏和技能按钮都排成菱形，EndHud 的连携提示和状态监视照常显示](docs/images/controller-battle.webp)

使用手柄时，游戏改用另一套界面：小队栏在左下角排成菱形，技能按钮在右下角排成菱形。EndHud 每次读取都会判断当前布局，战斗中也可以随时在键鼠和手柄之间切换。

| 手柄布局下 | |
|---|---|
| 干员名字、生命值、连携技冷却与就绪提示、技力、当前操作的干员、阵亡 | ✅ |
| 终结技充能：状态监视中的圆环随充能增长，就绪时高亮 | ✅ |
| 干员专属计数（如熔火）、连击及其层数 | ✅ |
| 少于 4 人的小队 | ✅ |
| 按住 LB 时 | 小队栏照常读取；终结技显示为带图标的大圆环，此时保持松开 LB 前的读数 |
| 战技冷却、等级 | 暂不识别 |

排轴中依赖战技状态的条件，在手柄布局下暂时无法判断。无需任何设置：拿起手柄操作后，游戏切换界面，EndHud 随之切换；改回键鼠同样如此。

## 常见问题

**游戏中看不到 EndHud**
请确认游戏使用无边框窗口或窗口模式，且 EndHud 正在托盘中运行。也可按 Ctrl+Shift+H 手动显示。

**干员显示为“1 号位”或识别错误**
小队栏出现后约一秒内完成识别。如有错误，按 Ctrl+Shift+M 打开菜单，在“干员识别”中为该位置指定正确的干员。

**提示略有延迟**
EndHud 约每 0.25 秒读取一次画面，提示可能比冷却结束稍晚出现。画面被特效遮挡时沿用上一次的读取结果，并在下次读取时更正。

**一直显示“正在识别小队栏”或出现其他问题**
调试面板会显示无法识别的原因。如需反馈，请右键托盘图标（或在菜单“通用”一栏中）选择“导出诊断信息”，桌面上会生成 `EndHud-diagnostics-日期时间.zip`，其中包含运行日志、设置和最近的几张游戏截图（UID 已遮挡，日志中不含 Windows 用户名）。请在 [GitHub Issues](https://github.com/Nedlitex/EndHud/issues) 或反馈帖中附上该文件。

**截图或录屏中没有 EndHud 的提示**
少数情况下，EndHud 无法获取游戏窗口的画面。此时如果系统支持，EndHud 改为读取屏幕上游戏所在的区域，并将自身 HUD 排除在截图和录屏之外，以免读取到自己的提示。在这种模式下，游戏需位于最前方并完整显示在屏幕内；被遮挡或超出屏幕时，调试面板会显示原因。

**设置保存位置**
`%APPDATA%\EndHud`。右键托盘图标选择“打开配置文件所在文件夹”即可打开；删除其中的 `config.json` 可恢复默认设置。
